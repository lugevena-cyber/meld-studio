# MELD 哼唱作曲工作台

一个在浏览器中运行的哼唱编曲工具：实时展示音高、识别调性与音阶，并可将旋律转换成电吉他、木吉他、钢琴、萨克斯、弦乐或合成器演奏。

## 启动

麦克风录音需要浏览器安全上下文。请在本目录的终端中运行：

```bash
python3 -m http.server 4173
```

然后打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

## 创作台

1. 点击“载入示例旋律”，无需麦克风即可体验完整流程。
2. 点击录音键后开始哼唱，停止录音会自动分析音高与调性。
3. 也可以上传 MP3、WAV、M4A 等人声音频，最长分析前 45 秒。
4. 在六种乐器中选择主奏音色，点击播放试听。
5. “导出 MIDI”可把识别出的音符导入其他 DAW 继续编曲。

## 我的作品

- 保存旋律时会同时记录调性、音符、乐器、速度、名称和创作备注。
- 支持搜索、按大调/小调筛选、重命名、复制、删除与继续编辑。
- 打开已保存作品后，可以切换音色、播放或导出 MIDI。
- 作品保存在当前浏览器的本地存储中；清理浏览器数据前请先导出 MIDI。

## 音色实验室

- 六种乐器均可通过屏幕钢琴或键盘 `A–K` 演奏。
- 可实时调整 ADSR 包络、亮度、空间和驱动参数。
- 内置六组预设音色，可将调好的参数保存为命名的“我的音色”。
- 保存后的音色会同步出现在创作台和编曲台的音色选择中。
- 按空格键可试听一段琶音，示波器会显示实时波形。

## 编曲台

- 进入编曲台后会建立主旋律、和声铺底与低音三条基础音轨。
- “智能配器”可根据当前旋律生成和声音程与低音声部。
- 支持继续添加使用内置或自定义音色的音轨。
- 每条音轨可独立静音、独奏、调整音量或删除。
- 多音轨会同时播放，并随作品和浏览器本地会话保存。

## 人声识别

- 音高曲线会先进行中值平滑、八度连续性修正和瞬时跳点过滤。
- 通过音高迟滞与最短稳定时长提取音符，短滑音不会被切分成大量碎片。
- 默认开启“仅调内音”：识别结果会吸附到当前音阶，画面只显示可用于继续作曲的音符。
- 当前音阶会在主视图与调性面板中高亮；播放时会同步点亮正在发声的音级。
- 可关闭“仅调内音”查看未吸附的原始识别结果。
- 节拍器使用 Web Audio 提前调度，支持连续拍点、首拍重音与视觉脉冲。

## 云端账户

- 支持 Supabase 邮箱登录与注册。
- 登录后，作品、编曲和自定义音色保存到云端账户，并支持跨设备访问。
- 音频识别仍在浏览器本地完成；只有作品的音符与参数数据会同步到云端。
- GitHub Pages 发布与 Supabase 配置步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。
